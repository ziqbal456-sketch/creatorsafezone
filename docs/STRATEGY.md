# Strategy and weekly loop
Help creators identify likely interface and crop conflicts before publishing. Rankings and AI citations are outcomes to measure, not promises.
Sequence: establish quality checks; verify existing evidence; collect authorized search baseline; improve tool completion; publish one differentiated guide at a time.
Weekly: inspect changed inputs, rank up to three opportunities by user value/evidence/effort/risk, select approved work, branch, test, preview, review, release, measure.
Track technical failures immediately. Compare search performance over comparable 28-day periods and annotate releases/seasonality. Missing analytics means data unavailable; do not infer private performance from public rankings.
Visitor analytics needs a separately approved privacy design; never collect media or filenames.
Weekly automation reads repository, public site and authorized sources, runs existing checks and recommends work. It does not edit, commit, merge, deploy or buy services. Notify only meaningful changes or decisions. Local scheduled work requires this machine and app available. Review the first two runs before expanding cadence.
