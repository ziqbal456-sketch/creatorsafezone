# Editorial and SEO standards
Use one descriptive title, one primary H1, a unique description and absolute production canonical per indexable page. Keep sitemap coverage and modification dates truthful.
Provide direct answers, useful examples, limitations and sources. Schema must match visible content; valid JSON alone proves neither accuracy nor search eligibility.
Never invent authors, testing, reviews or outcomes. Review FAQ schema for universal claims. Keep one primary intent per page.
Preview responses must be noindex; production must not inherit it. Robots directives are voluntary crawler requests, not protection against all scraping.
Automated checks detect structural regressions. Human review is still needed for source quality, accessibility, platform instructions and content overlap.
