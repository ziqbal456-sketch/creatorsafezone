Prepared locally on codex/homepage-value, October 1, 2026 (Asia/Karachi). Existing audit, branding and user changes were preserved. No commit, push, branch deployment or production promotion performed.

## Requested behavior

The homepage now uses all three shared-media surfaces by default. Above 980px, TikTok, Instagram Reels and YouTube Shorts appear in parallel. Below 981px, buttons select one visible card. Switching cards only changes visibility: all three surfaces remain mounted, keep their custom margins and share the media and marked regions. The same mobile controls also apply on /check-all-platforms. Reports and shared-placement results cover all three platforms even when only one card is visible.

Across all nine calculator pages, issues and suggestions, evidence notes, editor instructions and reference guides are ordinary visible sections. Tool settings, region controls and custom-margin fields remain optional controls. Reference guides now live inside main so the skip link includes them.

## Homepage content

Eight reference sections provide a calculated sample walkthrough; a registry-aligned margin table and state definitions; guide/report export choices; six problem-specific troubleshooting cards; a five-step final review checklist; six relevant tool/workflow resources; methodology, editorial responsibility and official sources; and visible FAQs. A small jump navigation keeps the longer page usable. No gated download or additional external runtime dependency was added.

Official resources reviewed and linked:

- [TikTok Auction In-Feed Ads](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads): safe zones depend on dimensions, caption length and additional formats. This supports choosing an appropriate ad template; it does not validate the organic checker margins.
- [YouTube Shorts upload guidance](https://support.google.com/youtube/answer/12779649?hl=en): square or vertical upload eligibility. This supports distinguishing the tool's 9:16 canvas from a universal upload requirement.
- [W3C accessible-media guidance](https://www.w3.org/WAI/media/av/): caption and access considerations beyond marked geometry. No accessibility compliance claim is made.

Trust is supported through transparent method, reproducible sample calculations, visible limitations, official references and editorial/about/privacy links. No personal expertise credentials, testimonials, device captures, platform endorsement or performance outcomes were invented. Four registry entries still need actual source captures.
