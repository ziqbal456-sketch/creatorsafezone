# CreatorSafeZone
Browser-based short-form video preview tools. Production: https://creatorsafezone.com.
Root HTML pages contain interfaces and browser scripts. measurement-registry.json records recommendations. worker.js forwards Cloudflare ASSETS and adds security headers. .assetsignore excludes internal material.

## Quality checks
Use Node.js 22 or later. Core checks require no installed dependencies:
```
node scripts/validate-site.mjs
node --test tests/*.test.mjs
node scripts/audit-content.mjs
```
npm run check wraps the first two; npm run audit reports editorial findings. npm run dry-run bundles through Wrangler without publishing and may need network access.
Run node scripts/smoke-test.mjs <actual-preview-url> for HTTP checks; it does not test browser interactions.

## Local styles and pinned tooling
Install the pinned tools with `pnpm install --frozen-lockfile --ignore-scripts` (pnpm 11.25.0). `pnpm run build:css` compiles support.css for the four informational pages; `pnpm run check:css` checks that the committed CSS matches their utility classes. CI checks this after installing the lockfile. Tool and guide pages use their existing handwritten CSS. All pages use system fonts.
`pnpm run preview` uses the Git-connected Wrangler branch preview. `pnpm run stage` uploads a production version for review; promotion still requires authorization. `pnpm run dry-run` builds without publishing. The package manifest, lockfile and pnpm workspace configuration are excluded from public assets.

## Shared brand
`brand.css` supplies the Signal Studio theme across tools, informational pages and guides. `brand-ui.js` authors the common header; after changing it, run `node scripts/sync-brand-headers.mjs` and regenerate support.css. Dynamic guide pages import the same header. The logo is a local SVG and the sharing card is generated by `scripts/render-brand-assets.py`. See docs/BRAND-2026-10-01.md for colors and verification.

Maintain `content/entity-registry.json` when adding guides or changing identity facts. It records stable author/publisher/website IDs, identity-link provenance and one owner per page intent. Identity tests compare the register with all static pages and every prepared guide. Follow `docs/ENTITY-IDENTITY-MANAGEMENT.md` alongside the keyword-research skill; topical references are not `sameAs` identities.

The homepage shows three shared-media previews on desktop and platform buttons below 981px. Switching the visible mobile card preserves all three surfaces, results, media and regions. Homepage reference content is authored in `content/homepage-reference.html`; run `node scripts/build-homepage-content.mjs` after editing it. The structural check catches stale output and links to missing or unpublished guides. Guidance below every calculator uses visible sections.

## Release loop
Roadmap item → feature branch → implementation → tests → push → GitHub checks and Cloudflare preview → PR review → authorized merge → main preview → authorized promotion → production verification.
CI has no deployment credentials. Branch protection is a separate GitHub setting: a workflow alone does not block merging.
See docs/ for strategy and standards, and CLOUDFLARE_DEPLOYMENT.md for release settings.
